## 审查背景

项目是基于 Tauri v2、Rust、React、TypeScript 的 Windows 文件管理器桌面应用。用户要求优化设置弹窗 UI 布局和快捷键设置交互。本轮只审查设计方案，不进行编码实现。

用户已确认的关键需求：

1. 设置弹窗采用“左侧紧凑分类导航 + 右侧分组表单”的 Windows 桌面偏好设置布局，参考截图的信息密度，但视觉更现代、干净。
2. 快捷键设置规则：输入框获得焦点后即可依次按键实时组合；输入框不再支持直接输入字符；失焦、Enter 或按下的快捷键松开时确认。
3. 本轮范围只覆盖设置弹窗整体布局和快捷键设置交互，不新增未实现的设置业务能力。

## 请重点审查

1. UI 布局是否符合 Windows 桌面文件管理器设置窗口最佳实践。
2. 左侧导航拆分是否合理，是否在“不新增业务能力”的前提下提升定位效率。
3. 右侧属性页是否足够整齐、干净、高密度，是否避免 Web 卡片堆叠感。
4. 快捷键捕获状态机是否完整，是否覆盖 Ctrl、Ctrl+Alt+P、Tab、Alt+Up、modifier-only 等情况。
5. “失焦、Enter 或按下的快捷键松开确认”的规则是否存在歧义或实现风险。
6. 禁止直接输入字符的设计是否充分。
7. 冲突检测方案是否与后端 `validate_shortcuts` 的 scope + accelerator 去重逻辑一致。
8. 是否存在会破坏现有 `WorkspaceState.settings.model`、Tauri IPC、远程连接 draft 保存语义的设计。
9. 测试计划是否覆盖主要风险。
10. 是否有无障碍、键盘导航、焦点管理或窗口尺寸方面的遗漏。
